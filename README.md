# HARAYA (DFA)

A web-based project that explores how Deterministic Finite Automata (DFA) can be used to detect and classify potential harassment situations from user input. It is designed as a simple, interactive system that helps users recognize concerning patterns and receive safety-oriented guidance.

## About the project

HARAYA is a DFA-based harassment detection prototype created to analyze descriptions of experiences and classify them as safe, potentially harmful, or clearly harassing. The project combines basic computational logic with a user-friendly web interface.

## The problem it solves
Many people struggle to recognize early warning signs of harassment, especially when the behavior is subtle or develops gradually. HARAYA aims to help users identify concerning patterns more clearly and encourage safer responses.

## Technologies used

- CSS for styling and layout
- JavaScript for the DFA logic and interactive behavior

## How to run

1. Open the project folder.
2. Launch the file [index.html](index.html) in a browser.
3. Alternatively, open it using a live server extension in VS Code for a smoother experience.

## Interface

The app features a simple interface with:
- a text box for describing an experience
- an Analyze button to process the input
- a results panel showing the classification
- a recommendations section with safety guidance
- an About page explaining the project concept
